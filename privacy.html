Privacy Policy

Application: Leto s dm — Trends fetcher · Last updated: 2026-05-15

This application is a non-commercial portfolio project. It uses the Pinterest API v5 to fetch aggregated, region-level trending keywords for the AT region via the /v5/trends/keywords/{region}/top/{trend_type} endpoint.

What data we access

  • Aggregated public Pinterest Trends data — region-level top and growing keywords. No user-level data.
  • No board content, no pin content, no follower lists, no account analytics beyond what is returned by the public Trends endpoints.

What data we store

  • The fetched top keywords (max ~16 entries per week) are written to a public JSON file (data.json) in the project's GitHub repository.
  • The access token is stored as a GitHub Actions Secret, accessible only to the workflow that calls the Pinterest API. It is never logged or exposed in the rendered site.

What data we do NOT collect

  • No personal data of Pinterest users.
  • No cookies, no analytics, no tracking on the rendered site.
  • No third-party data sharing.

How the data is used

Fetched keywords are displayed in a marketing case-study slide deck as "trending search inspiration for the AT region" — used illustratively to demonstrate data-driven content planning for a fictional summer campaign for dm drogerie markt. The project is a portfolio piece and is not used commercially, monetized, or redistributed.

Data retention

Weekly Trends snapshots are committed to a public Git history. Earlier snapshots can be removed on request by deleting the relevant commits and force-pushing — open an issue on the GitHub repository to request removal.
